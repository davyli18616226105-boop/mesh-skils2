# 四源配置与检索

## 固定入口

使用assets/sources.json中的原始URL，逐一检查与客户产品的相关性。类型/title为创建技能时观察值，只作路由提示；每次运行重新解析并取最新内容。

1. 分析DataAgent标准报价单：电子表格，含买断、订阅、功能及硬件要求。
2. 企业知识引擎刊例：文档，实际价格和功能表嵌入电子表格，含同步块和评论。
3. iDA销售公示刊例：文档，包含SaaS、私部订阅、私部买断及服务引用。
4. 数据智能体-智能营销Agent销售公示刊例：文档，包含公有云、私部、License、模型/资源、实施、维保和渠道区别。

不在技能中保存现行单价、最低折扣、账号、实施人天或维保费率作为默认值；不同客户/产品运行须重新匹配。

## 定位路径

- 用当前环境lark-drive解析wiki，按真实type读取。不同系统的产品ID/计费code与飞书token分开。
- 表：+workbook-info列真实子表；结合产品、部署和周期读取完整适用范围。合并值仅在已证实合并范围内传播。数值精度有歧义时读cells-get，不靠显示字符串推断。
- 文档：+fetch目录/章节/keyword。价格表位于table时取全适用行；位于sheet标签时提取真实token及sheet-id交给sheet。
- synced_reference：提取src-token、src-block-id，只读对应块/区间。不要以源文档已“废弃”判定目标同步块必然无效，也不能忽略废弃标记；核验该块当前是否适用及价格是否在目标刊例更新。
- 评论是解释与冲突线索，不默认具有报价批准效力；精确保存其对应位置。评论图像仅必要时读取，不传播人员或内部图片。
- 来源覆盖分别记录product/implementation/maintenance：matched、no_match、blocked、conflict。no_match只说明已读范围没有适用记录，不能冒称整个公司没有服务。
- 未提供真实产品时仅核对数据结构和入口，不为测试而假称客户需要截图示例产品。

## 常见歧义必须保留

- 标准报价单的“二套（生产、开发测试）”可能是报价包范围，不可直接把单价再乘2；需确认计量单位。
- 标题为订阅的段落若出现永久买断描述，不能作为买断授权或年订阅价格适用性证据。
- 不同表对文档额度的总则和订阅例外分别核验，不把文档数、GB、资源包数量转换为同一计费量。
- 费用“万”转换为“元”须保留转换记录；千tokens、百万tokens、秒、次、积分和包的计量不混同。
- 相同计费code但商品、周期、渠道、单位不同的记录不是可去重的一条。
- 指定四源只引用其他服务规则但未展开其内容时，先标缺口；没有用户授权，不自动去全公司或别的刊例借价。

## 完成判据

每个采用字段都能定位到当前实际来源、原句/源格及条件。读取范围/分页未完成或权限失败的来源标blocked；已有可用信息能生成草稿，但未知部分留空，绝不宣称四源均已完整匹配。
